
# Customer Shopping Behavior Analysis

This repository contains an end-to-end data analytics project examining 3,900 customer transaction records to uncover shopping patterns, optimize marketing strategies, and drive business revenue. The project integrates Python for exploratory data analysis (EDA) and feature engineering, MySQL for database management and analytical querying, and Power BI for interactive dashboard visualization.

---

## Technical Stack & Tools

* **Python (Pandas, NumPy, SQLAlchemy)**: Data loading, missing value imputation, text standardization, feature engineering, and database connection.
* **MySQL**: Relational database storage (`project_2` schema) and advanced SQL analytical queries.
* **Power BI**: Interactive visualization dashboard, custom themes (`CY26SU05.json`), data modeling, and reporting layout.
* **Jupyter Notebook**: Interactive environment for data cleaning and pipeline development.

---

## Data Pipeline & Methodology

### 1. Data Cleaning & Preprocessing (Python)
* **Dataset Overview**: Processed 3,900 total transaction records containing 18 initial feature columns.
* **Missing Value Handling**: Imputed 37 missing values in the `Review Rating` column using median ratings grouped by product `Category`.
* **Standardization**: Converted all column names to standard snake_case and renamed `purchase_amount_(usd)` to `purchase_amount`.
* **Redundancy Removal**: Dropped `promo_code_used` after verifying 100% equivalence with `discount_applied`.

### 2. Feature Engineering (Python)
* **Age Grouping**: Segmented customer ages into four quartile-based categories (`Young Adult`, `Adult`, `Middle-aged`, `Senior`) using `pd.qcut`.
* **Frequency Mapping**: Created `purchase_frequency_days` by converting categorical shopping frequencies (`Weekly` = 7 days, `Fortnightly` = 14 days, `Monthly` = 30 days, `Quarterly` = 90 days, `Annually` = 365 days) into numerical day intervals.

### 3. Database Integration (SQLAlchemy & MySQL)
* Established a connection to the local MySQL server instance (`localhost:3306`).
* Wrote cleaned data directly to table `customer` within schema `project_2` using SQLAlchemy engine.

## Business Analytics & SQL Queries

The project addresses 10 key business inquiries using structured SQL queries in `queries.sql`:

| Query ID | Objective | Key Method / SQL Technique |
| :--- | :--- | :--- |
| **Q1** | Compare total revenue generated by gender | `SUM(purchase_amount)` with `GROUP BY gender` |
| **Q2** | Identify discount users spending above average | Subquery comparing `purchase_amount` to overall `AVG()` |
| **Q3** | Top 5 products by average review rating | `ROUND(AVG(review_rating), 2)` sorted descending with `LIMIT 5` |
| **Q4** | Compare average spend between Standard vs. Express shipping | `WHERE shipping_type IN ('Standard', 'Express')` aggregate comparison |
| **Q5** | Revenue and customer count across subscription statuses | `COUNT()`, `AVG()`, and `SUM()` grouped by `subscription_status` |
| **Q6** | Top 5 products with highest discount rate | Conditional aggregation `SUM(CASE WHEN...) / COUNT(*)` |
| **Q7** | Segment customers into New (1), Returning (2-10), and Loyal (>10) | Common Table Expression (CTE) with `CASE WHEN` logic |
| **Q8** | Top 3 purchased items per product category | CTE using `ROW_NUMBER() OVER(PARTITION BY category ORDER BY...)` |
| **Q9** | Evaluate subscription rates for repeat buyers (>5 purchases) | Conditional rate calculation `SUM(previous_purchases > 5) / COUNT(*)` |
| **Q10** | Revenue contribution by age group | `SUM(purchase_amount)` grouped by engineered `age_group` |

## Key Insights & Visual Findings

* **Gender Revenue Distribution**: Female customers generate slightly higher total overall revenue compared to male customers.
* **Shipping Method Impact**: Customers opting for Express shipping spend approximately 12% more per transaction ($65 average) than those choosing Standard shipping ($58 average).
* **Subscription Performance**: Subscribers demonstrate 68% higher spend per transaction and generate 45% of total store revenue, exhibiting a 78% repeat loyalty rate.
* **Customer Segmentation**:
  * **Loyal Customers** (>10 previous purchases): Represent 15% of the total customer base.
  * **Returning Shoppers** (2–10 previous purchases): Account for 35% of total customers.
  * **New Customers** (1 purchase): Comprise 50% of total shoppers.
* **Top Performing Products**: Blouse, Dress, and Shirt lead customer satisfaction with top review ratings.
